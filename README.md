# Fraud Detection System – Adey Innovations Inc.

This project aims to improve fraud detection for e-commerce and credit card transactions using advanced machine learning techniques.

## Business Context
Fraud detection is critical in financial tech. This project balances the trade-off between security and user experience by building interpretable and accurate models.

## Project Structure
```
fraud_detection_project/
│
├── data/
│ ├── raw/ # Original CSVs
│ └── processed/ # Cleaned/engineered datasets
├── notebooks/ # Step-by-step analysis
├── src/ # Scripts for preprocessing, modeling, explainability
├── reports/ # EDA, final report
├── outputs/ # Models, figures
├── README.md
├── requirements.txt
└── .gitignore
```

## 🧪 Features
- Data preprocessing & cleaning
- Feature engineering
- Handling class imbalance
- Model training & evaluation
- Model explainability (SHAP)
